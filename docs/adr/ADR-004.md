# ADR-004. Servidor simulado de SAP Fiori tools

Estado: aceptada.

## Contexto

La definición de terminado exige verificar cada historia contra el servicio real y contra un servidor simulado. El desarrollo y las pruebas no pueden depender siempre de la conexión al sistema ni alterar sus datos.

El servicio es OData V4 con borrador. El servidor simulado clásico de SAPUI5 (`sap/ui/core/util/MockServer`) solo simula servicios OData V2 y se ejecuta dentro de la aplicación, en el navegador.

## Decisión

Se usa el servidor simulado de SAP Fiori tools, `@sap-ux/ui5-middleware-fe-mockserver`, como dependencia de desarrollo.

| Elemento | Valor |
|---|---|
| Configuración | `ui5-mock.yaml`: igual que `ui5.yaml`, sin el bloque `backend` y con el middleware `sap-fe-mockserver` |
| URL simulada | `/sap/opu/odata4/sap/zui_mnt_request_o4/srvd/sap/zui_mnt_request/0001`, la misma que la del servicio real |
| Metadatos | `webapp/localService/mainService/metadata.xml` |
| Datos | Un fichero JSON por conjunto de entidades en `webapp/localService/mainService/data/` |
| Scripts | `npm run start-mock` y `npm run start-mock-noflp` |

Los datos simulados se obtienen del servicio real, para que los dos modos partan del mismo contenido.

## Consecuencias

- La aplicación no cambia entre un modo y otro: el origen de datos del `manifest.json` es el mismo y solo cambia el fichero de configuración del servidor de desarrollo.
- El servidor simulado se ejecuta como middleware del servidor de desarrollo. La aplicación no contiene código de simulación, y la carpeta `localService` queda excluida de la compilación.
- `metadata.xml` es una copia de los metadatos del servicio. Si el servicio cambia, la copia y los datos simulados se actualizan a la vez. Las historias no modifican este fichero.
- Las reglas que calcula el servicio real (validaciones, recálculo del coste, control dinámico y contenido binario de los adjuntos) pueden no estar reproducidas en el servidor simulado. La verificación contra el servicio real sigue siendo obligatoria.
- Las pruebas contra el servidor simulado no alteran los datos del sistema.
